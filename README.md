DAGENS ÖVNING (HAMBURGEMENY)

1. Börja med att skapa en ny mapp på datorn för dagens uppgift, initiera git i mappen och länka
ditt lokala peropsitory till ett repository på GitHub. Det finns många sätt att göra det här på så
vi gör den här punkten tillsammans!
2. När git är initierat och länkat till GitHub är det dags att skapa dina första filer: index.html,
style.css, script.js & README.md. Länka ihop css och js filen med din html fil och lägg till en
kort titlen och beskrivning i readme filen. När det är gjort är det dags att göra din första
commit med GIT - gör det via Fork, VSCode eller Bash, du väljer!
3. Nu när projektet är på plats och GIT fungerar så är det dags att börja koda hamburgemenyn!
Lägg till en fixerad header med en fast höjd, samt lite annat innehåll i bodyn (Lorem Ipsum
paragrafer) - skapa nu en commit till på det du har gjort.
4. Lägg till ikon i headern för att toggla menyn och länka ikonens onclick till en funktion i JS. När
knappen klickas på så sätter du höjden på headern till 100vh. Se till att varannat klick öppnar/
stänger headern. Om du vill att det ska se lite mjukare ut kan du lägga till en css transition på
headern - skapa en commmit till på det du har gjort.
5. Fyll sedan resten av innehållet i headern och lägg sist till ikonen för att öka fontstorleken på
hela sidan - funktionerna du skapar i javascript skall dokumenteras med JSDoc!
